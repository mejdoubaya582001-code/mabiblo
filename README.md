# MaBiblio

Application Flutter de catalogue de livres réalisée
dans le cadre du TP « Listes et grilles ».

## Fonctionnalités
- Catalogue en liste (ListView, Card, ListTile)
- Galerie en grille responsive (GridView.builder)
- Filtres par genre et livres lus (CheckboxListTile)
- Données chargées et sauvegardées en JSON
